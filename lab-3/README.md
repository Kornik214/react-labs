## Стан

Для кожного рядка таблиці дайте відповідь на три питання з кроку 3 Thinking in
React (§4.7):

1. Чи залишаються ці дані незмінними з часом? Якщо так, це не стан.
2. Чи передаються вони від батьківського компонента через пропси? Якщо так, це
   не стан.
3. Чи можна обчислити їх на основі наявного стану чи пропсів? Якщо так, це
   точно не стан.

| Дані                                           | Стан? | Чому                                                                                                       |
| ---------------------------------------------- | ----- | ---------------------------------------------------------------------------------------------------------- |
| меню: категорії й позиції (`menu`)             | ні    | Залишається незмінним із часом (статичні початкові дані з `data.js`) і передається в таблицю через пропси. |
| текст у полі пошуку                            | так   | Змінюється з часом під час введення користувачем і не може бути обчислений з інших даних.                  |
| значення прапорця «Лише в наявності»           | так   | Змінюється з часом під час кліку користувача й не обчислюється з інших даних.                              |
| позиції, що залишаться після фільтрування      | ні    | Можна обчислити під час рендерингу на основі вихідного списку `menu`, тексту пошуку та прапорця наявності. |
| кількість позицій у заголовку категорії, «(4)» | ні    | Можна обчислити як довжину масиву відфільтрованих позицій у категорії (`items.length`).                    |

Стан житиме в компоненті: `App`, бо саме він є найближчим спільним батьківським компонентом для `SearchBar` (який змінює значення пошуку й прапорця) та `MenuTable` (якому ці значення потрібні для фільтрації меню).
